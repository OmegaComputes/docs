    Tools¶

    Tool What it does
    get_profile Get account profile
    get_onboarding_questionnaire, answer_compat_questions Onboarding questions
    resolve_requirements Turn a job description into requirements
    list_capacity Browse available capacity
    post_listing / create_listing Create a capacity listing (draft)
    update_listing, retire_listing, list_my_listings Manage listings
    get_validation_status, request_revalidation Listing validation
    create_pairing_code, list_machines, get_node_status, disconnect_machine Machines
    get_delivery_status, list_tranches, get_tranche, report_delivery_issue, approve_reprovision Delivery
    submit_job, list_jobs, get_job_logs, cancel_job Jobs on a deal
    announce_maintenance, drain_listing Seller operations
    get_username, set_username Username
    get_referral_code, claim_referral_code, list_referral_rewards, get_referral_terms Referrals

    Which tools you see depends on your key or sign-in scopes.
